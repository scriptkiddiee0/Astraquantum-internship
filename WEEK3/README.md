#  Week 3: Networking for Cybersecurity

## Summary

Built and analyzed a small routed network from a security practitioner's perspective, going beyond basic network setup into packet-level security reasoning.

- **Network Build** — Constructed a three-router, three-LAN topology in Cisco Packet Tracer with static routing across all segments.
- **Verification** — Confirmed reachability using `ping`, `traceroute`, and routing table inspection; simulated and recovered from an intentional route failure.
- **Packet-Level Analysis** — Used Simulation Mode to step through ARP, ICMP, and TCP/UDP exchanges, linking each protocol to real SOC detection scenarios.
- **Supporting Practice** — Completed six related rooms across LetsDefend and TryHackMe, including the Pickle Rick challenge.

Full methodology, evidence, and a knowledge check with reflection are documented in the report.
