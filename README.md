## Tools and Technologies Used

- **Platforms:** TryHackMe, LetsDefend
- **Operating Systems:** Linux (CLI fundamentals), Windows Server 2019, Windows Home/Pro
- **Networking:** ping, traceroute, ip route, subnetting, ARP, ICMP, TCP/IP, DNS, OSI model
- **Command Line:** Linux shell commands (cat, cd, cp, mv, touch, echo, whoami) and Windows CMD
- **Web Security:** HTTP methods and response codes, cookies, raw HTTP request/response inspection
- **System Security:** Windows Defender Firewall, BitLocker disk encryption, User Account Control (UAC)
- **Documentation:** Microsoft Word, screenshots for evidence capture

## Documentation Standard

Every task is documented as a single Word file, following a consistent internal format:

1. **Objective** — What the task aimed to achieve
2. **Approach** — The method or process followed
3. **Execution** — Commands, configurations, or steps performed
4. **Evidence** — Screenshots and outputs supporting completion, embedded directly in the document
5. **Outcome / Learning** — Result of the task and key takeaways
